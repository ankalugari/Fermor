# Fermor

Fermor is a responsive personal finance website that helps people understand spending, savings, and financial goals. It includes a sample dashboard and an optional sign-in screen. Authentication is not connected yet.

## Project Flow

1. Visitors land on the homepage and explore the product, dashboard, insights, and steps sections.
2. They can select **Sign in** from the navigation to open the sign-in form.
3. They can enter an email and password, or choose **Continue without signing in** to return to the homepage.
4. The sign-in form is for display only; it does not authenticate users or send their details.

## Technologies

- **React** - Builds the website from reusable components.
- **Vite** - Runs the local development server and creates production builds.
- **Tailwind CSS** - Styles the responsive interface.
- **Lucide React** - Provides interface icons.

## Commands

```bash
npm install       # Install dependencies
npm run dev       # Start the local development server
npm run lint      # Check code quality
npm run build     # Build for production
npm run preview   # Preview the production build
```
